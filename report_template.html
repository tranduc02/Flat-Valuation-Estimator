How did we estimate value?

Value on 31 Aug 2026
  1. Price index. Flats that sold twice show how prices moved between the two dates. We fitted a smoothed quarterly index from those pairs and used it to move every past sale to a common price level.
  2. Comparable history. For each flat we took the index-adjusted prices of earlier sales of the same flat, the same building (and same bedroom count), the same mesh block, and the same suburb and bedroom count. Training rows only see sales before their own date, so the model learns exactly what it can use on 31 August.
  3. Flat details. Floor (from the unit number), position in the building, bedrooms, bathrooms, parking, building size, distance to the harbour and to Town Hall.
  4. Model. LightGBM with a median (L1) loss on log prices, so it targets percentage error, which is what the within-10% score rewards. Recent sales count more (four-year half-life).
